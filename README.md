# 账本 App

单文件、纯本地、零依赖的记账页。数据存在浏览器 localStorage（key `ledger_v2`），不联网。

## 文件

| 路径 | 说明 |
|---|---|
| `账本.html` | **成品**，点开即用（118 KB 单文件，含图标） |
| `src/index.html` | 可编辑源文件（与成品相同） |
| `dist/` | **可部署的 PWA 版**：index.html + manifest.json + sw.js + icons/ |
| `build/账本-v2.html` | v2 设计快照 |
| `build/账本-美化版.html` | v1 快照 |
| `build/账本-美化前基线.html` | 最初原版，可回滚 |
| `build/style_v2.css` · `build/app.js` | 设计系统与主脚本（拆开看更方便） |

## 设计（v2 · 2026-10-21）

参考 Dribbble 上 2025 的深色金融 App（bento 卡片、glow、ring 进度）后重做：

- **极光底**：三团缓慢漂移的径向光 + 4.5% 噪点颗粒
- **主卡**：环形预算进度 + 近 7 日支出曲线 + 三格数据
- **月度额度条**：渐变填充 + 发光
- **本周对比条**：本周 vs 上周同期，带涨跌胶囊（无数据时自动隐藏）
- **统计页**：日支出面积图；分类占比环形图 + 图例（图标/名称/金额/百分比）
- **目标页**：总进度环形卡 + 每张卡百分比 + 编号版「存钱顺序」
- **底部 Dock**：悬浮毛玻璃胶囊 + 中间 FAB
- **记账面板**：一屏放下，彩色圆形分类图标 + 选中光环
- **微动效**：数字滚动、曲线描边、行渐入、切页淡入

## 部署（PWA）

`dist/` 里的四个文件直接丢到任意静态托管即可（GitHub Pages、Cloudflare Pages、Vercel）：

```bash
cd dist
git init && git add . && git commit -m "ledger v2"
git remote add origin git@github.com:<你的用户名>/<仓库>.git
git push -u origin main
# GitHub 仓库 Settings → Pages → Source 选 main / root
```

手机 Chrome 打开部署地址 → 菜单「添加到主屏幕」，就是独立 App（standalone + 离线缓存）。
注意：不同域名 = 不同 localStorage，换地址后要么导出导入备份，要么固定用一个地址。

## 记账面板尺寸

键盘键位、金额字号、分类图标随视口高度走：

| 视口高 | 键高 | 键盘字号 | 分类图标 | 面板高度（393 宽） |
|---|---|---|---|---|
| > 780px | 40 | 17.5 | 46 | ~560 |
| ≤ 780px（带地址栏的浏览器） | 37 | 16.5 | 38 | ~471 |

最近一次改动把键盘从 22px/53px 高收到 17px/40px，金额 40→34，分类图标 50→46；再配合 `@media (max-height:780px)` 继续收一档。

## 自适应（2026-10-21）

- 页面固定为视口高度（`html,body{height:100%;overflow:hidden}`），**不再整页滚动**
- 明细页是 flex 列：顶部仪表盘固定，`#list` 自己内部滚动 → 首屏就能看到最近几笔
- 按视口高度分三档压缩：`≤900px` 收紧间距、`≤720px` 隐藏曲线图并缩小字号、`≤620px` 再隐藏小卡
- 宽屏（`≥760px`）整体限宽 560px 居中，Dock 同步限宽，变成「手机 App 列」而不是拉满整屏
- 统计/目标/设置三页改为内部滚动（内容多时仍可滚到底）
- 删掉了与主卡重复的「本月额度已用」卡片，省一屏高度

## 当月天数（自动）

- `budget()` 直接用 `new Date(y, m+1, 0).getDate()` 取当月真实天数，跨月自动切换（2 月 28 / 闰年 29、4 月 30、31 天的月份 31）
- 设置页原来的「当月天数」输入框已去掉，改成只读显示 + 说明「按日历自动切换，不用手填」
- `cfg.mdays` 字段废弃；旧备份里带着也会被忽略，不影响导入

## 已知注意

- WebKit 下若把带 `mix-blend-mode` 的伪元素和 flex 小字号文本混在一起，个别文字会被按 1x 光栅化（看起来缩小 3 倍）。主卡标题已移到 `.hval` 里规避。
- 环形进度使用显式 ARC path（`arcPath()`），不用 dashoffset —— 后者在本机 WebKit 上方向是反的。

## 改法

样式集中在 `账本.html` 的 `<style>` 里；业务脚本在文末 `<script>`。
改完 `账本.html` 后执行：
`cp 账本.html src/index.html && cp 账本.html build/账本-v2.html`
部署版需再跑一次「去掉内联 manifest、换真图标」的同步（README 见 git 记录或在 `build/` 留档）。
